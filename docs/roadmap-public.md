# Public roadmap

Snapshot **2026-11-16**. [Windows v0.2.4](https://github.com/MatrixChill/cybersafe-assistant/releases/tag/v0.2.4) is the stable distribution. [Arch Preview 3](linux/README.md) and [Nigor Preview 1](nigor-os/README.md) are experimental. This map records evidence and next boundaries without promising dates.

| State | Capability / next step | Evidence boundary |
|---|---|---|
| Published | Multi-engine scanning, history, quarantine, MATRIX and diagnostics | See the edition guides. Availability and lab tests do not establish universal detection. |
| Published Windows fix | ClamAV process-lifecycle recovery in v0.2.4 | Device-specific confirmation remains separate. Preserve timeouts and inconclusives. |
| Experimental, published | Dedicated Nigor package, local entry without account, optional login and native integration adapter | Lab build, migration and local API refusal evidence in the Nigor release. Physical Nigor acceptance remains pending. |
| Implemented / lab-tested | Linux batching, optional persistent clamd, cross-filesystem quarantine | Workload and memory details belong to the exact release. Physical USB and broader hardware require validation. |
| Implemented / partial acceptance | Ed25519 metadata, edition compatibility, protected staging and consented installation requests | Full feed-to-graphical-authorization-to-restart proof remains distinct from helper/pacman lab transactions. |
| External prerequisites | Legitimate Windows Authenticode publisher and signed installed-update proof | Publisher identity, certificate and authorized installed trial required. |
| Validation pending | Nigor keyring/session restart, bar, notifications, graphical polkit, sensors and USB | Native integration belongs to the OS; CyberSafe retains engine/client responsibility. |
| Evidence pending | Current-version screenshots and benign recordings | Capture real versions, redact private data and preserve original durations. |
| Experimental lab only | Prevention before execution | Distributed Linux protection remains after-write monitoring. |

Original code has the [owner-approved MIT license](licensing.md). Third-party notices and compatibility need review for each distribution.

The [October roadmap](ROADMAP.md) and [PAP evidence](../PAP-EVIDENCIAS-TECNICAS/README.md) keep their historical context. Proposals are welcome through [contribution guidance](../CONTRIBUTING.md).
