## Update channels

| Route | Consumers and current role |
|---|---|
| Windows `releases/latest` | Windows Stable remains v0.2.4. Manual installation while legitimate Authenticode and installed update acceptance are incomplete. |
| `linux-update-channel` | Legacy Arch feed intentionally retained at Preview 2. Clients using its old installation path need a manual migration. |
| `linux-update-channel-v2` | Route reserved for compatible generic Arch clients. No public release at this review. Preview 3 users should use the published manual installation guide. |
| [`nigor-update-channel-v2`](https://github.com/MatrixChill/cybersafe-assistant/releases/tag/nigor-update-channel-v2) | Nigor-only signed v2 experimental manifest. Preview 1 is the bootstrap package. No compatible later version is promised by the presence of this feed. |
| `channel-preview` | Historical Windows Preview feed, separate from the Linux and Nigor contracts. |

Channels carry manifests and signatures. Use an edition's release page to install the application. Stable and Experimental have separate manifests. Ed25519 authenticity, hash and size, edition, client floor, consent and system authorization all matter. A successful helper test does not demonstrate the full installed graphical update path.
