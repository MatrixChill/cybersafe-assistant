# CyberSafe para Windows

[English](README.md) · [Todas as edições](../downloads.pt-PT.md)

**Estável v0.2.4**, Windows 10/11 x64. Consulte o [guia de instalação, atualização e recuperação](../installation.pt-PT.md) e a [release oficial](https://github.com/MatrixChill/cybersafe-assistant/releases/tag/v0.2.4).

O pacote inclui a aplicação Electron e componentes empacotados. Definições ClamAV, regras YARA e saúde dos motores continuam a fazer parte da aceitação em execução. Medições nativas Windows e terminação individual protegida têm contratos específicos da plataforma.

O Setup não tem Authenticode e a atualização instalada mantém-se manual. Lacunas do watcher, timeouts ClamAV e sensores ausentes continuam visíveis. WFP exige provisionamento separado. [Limites de segurança](../../SECURITY.md) · [Arquitetura](../architecture/README.pt-PT.md) · [MATRIX](../matrix.md).

Antes de atualizar, preserve o Setup anterior verificado e um backup frio consistente. Para remover, use Definições do Windows e o desinstalador oficial. O guia de instalação explica a recuperação.
