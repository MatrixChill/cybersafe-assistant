# CyberSafe for Windows

[Português de Portugal](README.pt-PT.md) · [All editions](../downloads.md)

**Stable v0.2.4**, Windows 10/11 x64. Use the [installation, update and recovery guide](../installation.md) and [official release](https://github.com/MatrixChill/cybersafe-assistant/releases/tag/v0.2.4).

The package includes the Electron app and packaged components. ClamAV definitions, YARA rules and engine health remain part of runtime acceptance. Windows-native measurements and protected individual process termination have platform-specific contracts.

The Setup lacks Authenticode and the installed update path remains manual. Watcher gaps, ClamAV timeouts and missing sensors remain visible. WFP requires separate provisioning. [Security limits](../../SECURITY.md) · [Architecture](../architecture/README.md) · [MATRIX](../matrix.md) (PT-PT).

Keep an older verified Setup and a consistent cold backup before upgrading. For removal use Windows Settings and the official uninstaller. Full recovery instructions are in the installation guide.
