# Support / Suporte

[Downloads](downloads.md) · [FAQ](faq.md) · [Contribute](../CONTRIBUTING.md)

For installation and usage, choose [Windows](installation.md), [Arch](linux/README.md) or [Nigor](nigor-os/README.md). Start with the release notes and the health/diagnostic state shown by that edition.

For an ordinary reproducible bug, use the repository's [Issues](https://github.com/MatrixChill/cybersafe-assistant/issues). Include edition, app/package version, OS and architecture, safe reproduction, expected result and a short redacted log. Separate a measured latency from an estimated duration. A minimal report may be written in English or Portuguese.

Remove credentials, account details, personal paths, process command lines and private notifications from screenshots. Never attach personal databases, quarantine contents or malware. Suspected vulnerabilities follow [SECURITY.md](../SECURITY.md) before any public details.

This independently developed project has no guaranteed support time, managed response service or certification claim. Contributions and reproducible observations help determine the next work.

Para suporte em português, indique edição e versão, ambiente, passos mínimos benignos e resultado. Consulte os guias [Windows](installation.pt-PT.md), [Arch](linux/README.pt-PT.md) e [Nigor](nigor-os/README.pt-PT.md). Proteja os dados pessoais e use a política de segurança para vulnerabilidades.
