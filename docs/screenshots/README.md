# Capturas de ecrã

Esta pasta está deliberadamente vazia: a entrega não inclui capturas da interface.

As sessões de validação de outubro foram registadas em texto e em dados técnicos, não em
imagens. As capturas referidas durante os testes não chegaram a ser entregues, e as imagens
produzidas nessa altura mostram o ecrã completo, com dados do computador e da conta de teste.
Reaproveitar imagens antigas também não serve: já não representam o estado atual da aplicação.
Por isso, nenhuma imagem foi publicada e nenhuma foi inventada.

## O que uma captura precisa de cumprir antes de entrar aqui

1. **Origem confirmada.** Tem de vir de uma sessão identificada e corresponder à versão
   documentada.
2. **Sem dados pessoais.** Nome de conta, correio eletrónico, caminhos com o nome do
   utilizador, nomes de rede e processos privados têm de estar ocultados.
3. **Sem estados enganadores.** Uma imagem de erro ou de carregamento não pode ser usada para
   ilustrar um estado funcional.
4. **Verificação visual.** Alguém tem de olhar para a imagem depois de sanitizada e confirmar
   que não sobrou nada sensível.

Imagens de identidade visual do projeto — logótipo, capa, ícones — não substituem capturas de
funcionamento e não provam que a aplicação faz o que o texto descreve.
