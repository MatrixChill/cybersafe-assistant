# Record a real 60–90 second demo

**Prepared script, not an executed test or an existing video.** Record the installed version actually used and put its version/date in the title. The tracked v0.2.0 screenshots remain historical; do not relabel them as v0.2.4.

## Preparation

Use a test account with no personal data, a small folder of disposable benign text files, and a neutral desktop. Hide private paths, account details, notifications and credentials before recording. Keep Windows protections enabled. Never show quarantine contents, create malware, terminate personal processes or change protection settings for the video. Obtain consent before recording anyone else.

Do not edit a failure into a success. If scanning takes longer than the slot, show a labelled time cut and retain the real duration/results; a 90-second presentation is not a scan-speed benchmark. If a sensor/provider is unavailable, show that honestly.

## Capture checklist

- Record version, date, Windows build, benign corpus description and actual scan count/duration.
- Review every frame for private data and false coverage claims; do not expose the local account or process command lines.
- Use captions and readable zoom; preserve aspect ratio and offer reduced-motion viewing where possible.
- Publish only after owner review. Add a real video link to the README once available, with version and context.
- Put new authentic, privacy-reviewed images under `docs/images/` with versioned filenames and update its index. Do not overwrite historical evidence.
